# SysEvol

SysEvol builds open-source tools for understanding, searching, and evolving
software systems with AI.

This repository is the public guide to the projects, documentation, and
community around SysEvol.

## Projects

### [CodeNib](projects/codenib.md)

CodeNib turns a repository into a searchable Wiki and a reusable context
service for coding agents. It combines code indexing, hybrid retrieval,
structural navigation, and MCP integrations in a local-first workflow.

- [Source repository](https://github.com/sysevol-ai/CodeNib)
- [Documentation](https://docs.codenib.ai/)
- [Quickstart](https://docs.codenib.ai/quickstart/)
- [PyPI package](https://pypi.org/project/codenib/)
