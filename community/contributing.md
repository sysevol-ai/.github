# Contributing

SysEvol welcomes code, documentation, experiments, issue reports, and ideas.

## Ways to participate

- Open an issue in the relevant [GitHub repository](https://github.com/sysevol-ai).
- Share questions and prototypes in [Discord](https://discord.gg/ySer6CGn4).
- Explore and discuss released models, datasets, and artifacts on
  [Hugging Face](https://huggingface.co/sysevol-ai).
- For code changes, read the contribution instructions in the target project
  before opening a pull request.

Keep reports reproducible, discussions constructive, and contributions scoped
to one clear problem whenever possible.
